# Engra Releases

Release distribution repository for Engra CLI binaries, SBOMs, and checksums.

## Installation via Homebrew

```bash
brew tap arenberg-engineering/tap
brew install engra
```

## Direct Download

Download the release binary from the [Releases](https://github.com/arenberg-engineering/engra-releases/releases) page and verify checksums against `SHA256SUMS`.
